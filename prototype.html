We have published every line of our robot code since 2011.

Sixteen consecutive seasons, in the open, on GitHub. C++ through 2015, Java since. One season in D, because a student wanted to try it.

We also ship our own tools. ShooterTargeting solves launch coefficients for a given shooter geometry. ArmSim listens on NetworkTables to simulate arm motion before the arm exists.

If you employ engineers, hand them this link. It is the fastest way to judge whether we are worth funding.
